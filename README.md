# duely

A simple assignment planner for students: add assignments, plan which day you'll work on each one, and check them off.

## Run it

Requires [Node.js](https://nodejs.org/) 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build for production

```bash
npm run build
npm run preview
```

Data is saved in your browser's localStorage, so no database or setup is needed.
